## 収集する情報

### ユーザー ID

Bot の利用時、次の機能では Telegram のユーザー ID が記録され、設定や生成結果と関連付けられる場合があります。

- 返信形式のカスタマイズ
- Telegraph ページの生成
- 作者の全作品の書き出し
- お気に入り機能（予定）
- 作者作品の配信機能（予定）

その他の通常操作では、送信した作品とユーザー ID を関連付けて保存しません。

### IP アドレス

次の場合、Bot または Cloudflare が現在の IP アドレスを取得する場合があります。

- Telegraph ページをブラウザで開いた場合
  - Cloudflare が元画像への直接リンクを提供します。
  - Bot が動画への直接リンクを提供します。
- このドキュメントへアクセスした場合

Telegram の Instant View だけを利用した場合、Telegraph ページへの通信はこのサービスを経由しません。

## セキュリティ

Bot は利用者を追跡するリンクを追加せず、利用傾向を第三者へ提供しません。公開 GitHub 版と同じソースコードで動作します。

## 改定

このポリシーは更新されることがあります。更新後も Bot を利用する場合、更新後の内容に同意したものとみなします。
